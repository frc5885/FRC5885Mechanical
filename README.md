## 🤖 Welcome to the WiredCats Mechanical Team! 🛠️
## FRC Team 5885 | Villanova WiredCats | LaSalle, Ontario, Canada | [wiredcats5885.ca](https://www.wiredcats5885.ca)

Welcome to the official GitHub repository for FRC Team 5885, the Villanova WiredCats! This is a central hub for our team's mechanical design and documentation. Whether you are a new member eager to learn or a veteran contributor, this repository will be your primary resource for all things related to our robot's mechanical subsystems.

Our goal is to foster a collaborative environment where you can develop skills in engineering, CAD, and teamwork. We're excited to have you on the team!

## 🚀 Getting Started
  - Use your @mytools2go and sign up for an [AutoDesk Inventor License](https://www.autodesk.com/education/support)! The educational license is free! If you have a PC at home, we highly reccomend that you install it so you can work on it anytime!

  - Get Discord! We typically use discord to communicate between students, mentors, etc.

  - If you're reading this without a github account, get one and ask a mentor to add you to the team! Make sure to use your real name for the account, no nicknames and be professional!
    
  - Check out our help documents and guides to get started on learning how we do things!

  - If you're looking for more, explore our past robot designs! This is the best way to understand our mechanical systems and design approach.

⚙️ How to Contribute

We encourage all mechanical team members to contribute. To ensure a smooth workflow, please follow the github and design guides listed in the [**1\_Generic Guides**](https://github.com/frc5885/FRC5885Mechanical/tree/main/1_Generic%20Guides) folder

Learn CAD! CAD is probably one of the most powerful tools, it lets you design, simulate, and help build everything to make sure you get everthing right the first time!

If you have questions or need assistance with GitHub, please ask a mentor. We are here to help you succeed!
